# خادم مندس Multiplayer

ارفع **محتويات** هذا المجلد إلى:
`public_html/apps/imposter/`

ثم افتح:
`https://scrptaty.com/apps/imposter/api/health.php`

يجب أن تحصل على `"ok": true`.

## لماذا هذا الخادم مناسب للاستضافة المشتركة؟

- PHP فقط، بدون Node وبدون WebSocket.
- لا يحتاج MySQL ولا SQLite.
- كل غرفة تُخزّن مؤقتاً كملف JSON محمي داخل `private/rooms`.
- يستخدم `flock()` لمنع تعارض الكتابة عند إرسال أكثر من لاعب في نفس اللحظة.
- التطبيق يعمل بتحديث سريع Polling كل ~700ms، وهو مناسب للعبة الدور هذه.
- الغرف تنتهي تلقائياً بعد 8 ساعات، ويمكن تشغيل `api/cleanup.php` من Cron كل ساعة.

مجلد `private` محمي بواسطة `.htaccess` ولا ينبغي أن يكون قابلاً للقراءة من الويب.
